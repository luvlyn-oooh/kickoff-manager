# 킥오프 매니저 ⚽

브라우저에서 돌아가는 축구 감독 시뮬레이션 게임입니다. 설치가 필요 없습니다.

## 실행
- `index.html`을 더블클릭해 브라우저로 열면 됩니다.
- 또는 로컬 서버: `python -m http.server 8777` 후 http://localhost:8777

## 휴대폰에서 하기 📱
화면 크기에 맞춰 자동으로 모바일 화면(세로 경기장, 하단 탭 바, 바텀 시트 메뉴)으로 바뀝니다.

- **같은 Wi-Fi에서 바로 해보기**: PC에서 `python -m http.server 8777` 실행 → 휴대폰 브라우저에서 `http://<PC의 IP 주소>:8777` 접속
  (이 방식은 웹페이지로만 열리고, 앱 설치·오프라인 실행은 안 됩니다)
- **앱처럼 설치하기 (PWA)**: 이 폴더를 HTTPS 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 올린 뒤 휴대폰으로 접속
  - 안드로이드(Chrome): 타이틀 화면의 **📲 앱으로 설치** 버튼
  - 아이폰(Safari): **공유 → 홈 화면에 추가**
  - 설치 후에는 홈 화면 아이콘으로 실행되고 인터넷 없이도 플레이할 수 있습니다.
- 경기 중 화면 꺼짐 방지, 우리 팀 득점 시 진동을 지원합니다.
- `sw.js`의 `VERSION`을 올리면 설치된 앱이 새 버전으로 갱신됩니다. 아이콘은 `python dev/make_icons.py`로 다시 만들 수 있습니다.

## 게임 방법
1. 8개 구단 중 하나를 골라 감독으로 부임합니다.
2. **선수단·전술**: 포메이션(4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 5-3-2), 경기 성향, 압박 강도를 정하고 선발 명단을 짭니다.
3. **훈련**: 주간 훈련 방향(균형/공격/수비/피지컬/휴식)을 정합니다. 어린 선수일수록 잘 성장합니다.
4. **경기 시작**: 22명의 선수가 실시간으로 움직이는 경기를 지켜보며 성향·압박을 바꾸고 교체 카드(5장)를 씁니다.
   - `Space` 일시정지, 배속 ×1~×8, `⏭ 결과로` 즉시 종료
5. 14라운드가 끝나면 시즌 결산 → 나이 증가·성장·은퇴가 반영된 다음 시즌이 시작됩니다.

진행 상황은 매 라운드 브라우저(localStorage)에 자동 저장됩니다.

## 구조
| 파일 | 역할 |
|---|---|
| `js/data.js` | 구단·이름·포메이션 데이터, 선수 생성 |
| `js/engine.js` | 실시간 경기 엔진 (위치 선정, 패스·드리블·슈팅·태클·세트피스) |
| `js/game.js` | 리그 일정, 순위, 훈련/성장, 부상·징계, 저장 |
| `js/render.js` | 캔버스 경기장 렌더링 |
| `js/ui.js` | 화면 구성과 입력 처리 |
| `dev/balance.html` | 밸런스 측정용 페이지 (AI 경기 수십 번 돌려 평균 득점·슈팅 등 출력) |
